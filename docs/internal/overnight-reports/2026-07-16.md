### Storage authority, freshness, and compatibility details

The resolver trims input, expands tilde, resolves relative agent paths from
cwd, resolves relative session paths from the selected agent authority, and
uses the installed SDK's `homedir/.pi/agent` default only when neither setting
is supplied. The default `data/outcomes/sessions` suffix is applied exactly
once. Backend child creation and host client logging share
the same resolution contract.

Create and fork use the resolved authority. Discovery covers configured flat
sessions and immediate child directories plus legacy
`${agentDir}/sessions` and its immediate children, matching installed SDK
layout. Canonical, normalized paths win duplicates; Windows comparison is
case-insensitive. SDK `firstMessage` metadata supplies unnamed labels without
rereading transcript bodies. Explicit-file open/recovery remains explicit and
does not migrate the file.

The catalog caches expensive discovery but records a filename signature from
before cold discovery. Every 10 seconds an unref'd, overlap-guarded poll checks
that inexpensive signature. Create/delete/rename invalidates discovery;
ordinary appends do not. `ENOENT`/`ENOTDIR` are empty roots; access/busy and
other inventory failures preserve the last complete catalog and do not emit a
truncated session list. Disposal stops future publication. One live
characterization saw 601 legacy SDK sessions in 5,618.2 ms and a compatibility
catalog of 653 unique sessions in 8,449.6 ms cold, then 0.25–0.44 ms cached.
Those are single old observations. The ten-sample signature distribution above
measures a different operation and is not presented as a cold-start speedup.

### Transcript and render-completeness invariants

Host paging remains explicit CQRS: only the requested bounded window is sent,
and top/bottom gap rows remain visible whenever data is omitted. Each gap
reports the exact omitted row count and how many rows the next action requests,
including while loading. No transcript row becomes unreachable; the larger
page changes navigation effort, not retention or serialization.

The tab comparator covers only tab-visible names, pending state, run summaries,
relevant lists/scalars, and callback identities. The tool body comparator uses
exact lifecycle fields plus sequence and stabilized context. Real changes cross
both barriers. The view-state stabilizer recursively compares JSON-like arrays
and plain objects and fails open on cycles/unsupported prototypes, which favors
correct rerendering over a false equality. `TranscriptSurface` is keyed by
active session path to prevent terminal/body state crossing a session boundary.
